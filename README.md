# «Семь ночей»

Telegram-бот-компаньон для программы из семи аудиопрактик, админка для специалиста и лендинг с интерактивным тестом.

Человек проходит на сайте тест «Индекс внутренней опоры», уходит по кнопке в бота и семь вечеров подряд получает по одной практике. Каждый вечер он отвечает цифрой от нуля до десяти до практики и после неё. На седьмой вечер бот присылает картинку с графиком за неделю и итог «было и стало».

## Что здесь есть

| Часть | Где | Что делает |
|---|---|---|
| Бот | `src/bot/`, `src/scheduler/` | Ведёт человека семь вечеров: замер до, практика, замер после, график в конце |
| Админка | `src/admin-api/`, `web/admin/` | Вся история и статистика; загрузка практик и правка текстов бота |
| Лендинг | `web/landing/` | Одна страница на русском с тестом из семи ползунков; кнопка ведёт в бота |
| Практики | `content/practices/`, `content/audio/` | Девять сценариев и их озвучка |
| Озвучка | `scripts/tts.ts`, `scripts/generate-audio.ts` | Сценарий → mp3 через Azure Speech |

Бот: [@ensoma_robot](https://t.me/ensoma_robot).

## Быстрый старт

```bash
cd ~/7days
cp .env.example .env          # и заполнить TELEGRAM_BOT_TOKEN, ADMIN_PASSWORD
npm install
npx tsx scripts/seed.ts       # миграции + тексты по умолчанию + практики из файлов
npx tsx src/index.ts          # бот + планировщик + админка + лендинг на одном порту
```

Открыть: лендинг `http://<host>:3700/`, админка `http://<host>:3700/admin/`.

Как сервис:

```bash
cp deploy/seven-nights.service ~/.config/systemd/user/
systemctl --user daemon-reload
systemctl --user enable --now seven-nights
systemctl --user status seven-nights
journalctl --user -u seven-nights -f
```

> Останавливать только через `systemctl --user stop seven-nights`. **Никогда** не гасить по `pkill -f index.ts` — на этой машине такой шаблон уже ронял чужой прод.

## Как это устроено

**Одно состояние и один срок на человека.** У каждого пользователя в базе есть `state` (где он сейчас в диалоге) и `due_at` (когда с ним нужно что-то сделать). Планировщик раз в тридцать секунд выбирает всех, у кого срок наступил, и выполняет переход. Никаких таймеров в памяти: перезапуск процесса ничего не теряет и ничего не дублирует.

**Ритуальная дата.** Вечер живёт внутри «ритуальной даты» — это локальная дата момента `сейчас минус четыре часа`. На одну ритуальную дату — максимум один засчитанный вечер. Одно это определение закрывает «ответил в половине первого ночи», «вечерний час в 23:30», «нажал „Практика сейчас“ за минуту до пинга» и «два вечера в один день».

**Вечер засчитывается в момент успешной отправки аудио** — не по кнопке «Готово» и не по замеру «после». Уснул под практику, не ответив, — вечер всё равно пройден, утром бот мягко спросит, как ты.

**Пропуск сдвигает программу, а не теряет её.** Номер вечера не растёт, пока практика не отправлена. Человек всегда проходит все семь; растёт только календарная длина.

**Часовой пояс без вопроса о часовом поясе.** Telegram не сообщает зону. Бот показывает три кнопки с реальным временем («18:42», «17:42», «19:42»), человек жмёт свою — и смещение вычислено. Хранится только смещение в минутах, всё время в базе — UTC.

Подробности — в `docs/design-bot.md` (механика и все тексты) и `docs/architecture.md` (схема БД, таблица переходов, контракты модулей).

## Практики

Девять сценариев в трёх категориях; человек каждый вечер выбирает, что ему ближе.

| Категория | Практики |
|---|---|
| 😴 Сон и расслабление | Приземление, Тепло по телу, Отпустить день, Случайные картинки |
| 🌿 Тревога и стресс | Два вдоха и выдох, Пять вещей вокруг, Рука на сердце |
| 🌅 Настроиться на день | Настроить день, Перед разговором |

Каждый сценарий — markdown с шапкой (`slug`, `title`, `category`, `intro` — две строки для сообщения бота) и телом, где паузы размечены `[[pause:8]]` или `<break time="2.0s" />`.

```bash
npx tsx scripts/generate-audio.ts            # озвучить всё, чего нет или что изменилось
npx tsx scripts/generate-audio.ts --dry-run  # только посчитать знаки и запросы
npx tsx scripts/generate-audio.ts --force    # перегенерировать всё
npx tsx scripts/voice-samples.ts             # образцы голосов для выбора
```

**Голос по умолчанию — `ru-RU-SvetlanaNeural`**, потому что он читает ровно так, как написано. Генеративная `ru-RU-Masha:MAI-Voice-2` звучит живее, но сама расставляет паузы (23 секунды собственных пауз на 170 знаков) и игнорирует замедление — ритмом начинает распоряжаться модель, а не автор сценария, и практика раздувается вдвое. Замеры и обоснование — `docs/tts-decision.md`. Смена голоса — строка `TTS_VOICE` в `.env` и `--force`; квоты Azure (полмиллиона знаков в месяц против нужных двадцати шести тысяч) хватает на десятки перегенераций.

Готовых mp3 в репозитории нет — восемьдесят два мегабайта сгенерированного звука там не нужны. Они собираются одной командой из сценариев, нужен свой ключ Azure Speech: переменные `AZURE_SPEECH_KEY` и `AZURE_SPEECH_REGION` в окружении или в `~/.config/seven-nights/azure-speech.env`. Образцы голосов в `content/audio/samples/` оставлены — по ним выбирают голос.

> **Это заглушки.** Тексты и голос — демонстрационные, чтобы продукт можно было увидеть и пройти целиком. Настоящий специалист заменит их своим голосом через админку.

## Тест «Индекс внутренней опоры»

Семь вопросов с ползунками от нуля до десяти на лендинге. Индекс = сумма ÷ 70 × 100, показывается один из пяти текстов. Тексты заданы автором и **меняться не должны** — они лежат в `docs/quiz-spec.md`, а тест `tests/quiz.test.ts` сверяет их с реализацией символ в символ и проверяет границы результата с обеих сторон.

Результат уходит в бота через ссылку `https://t.me/ensoma_robot?start=q<сумма>`. Бот сохраняет индекс, один раз упоминает его в приветствии, а после седьмого вечера по кнопке предлагает пройти те же семь вопросов внутри Telegram и показывает «было 60 → стало 74». Контракт — `docs/quiz-bot-integration.md`.

Лендинг ничего не отправляет на сервер: ответы живут только в `localStorage` браузера.

## Проверка

```bash
npx vitest run        # тесты
npx tsc --noEmit      # типы
npm run build:admin   # сборка админки
```

Приёмка из технического задания проверяется демо-режимом, в котором вечер идёт пару минут: включается в админке или командой `/demo <секрет>`. За четверть часа проходятся все семь вечеров, включая пропуск и финальный график.

## Чего здесь намеренно нет

Оплаты, кодов доступа и страницы «спасибо» — владелец решил их выпилить: вход в бота свободный.

Имени, телефона, почты, username — бот хранит только Telegram ID, удобный час, номер вечера и цифры замеров. Картинку с графиком можно переслать кому угодно: на ней нет ни одного личного данного.

Медицинских обещаний. Ни в одном сценарии, ни в одном тексте бота, ни на лендинге.
